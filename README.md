## Environment & Setup

This repository uses [`uv`](https://docs.astral.sh/uv/) for Python package and virtual environment management.

### Prerequisites

- Python `>= 3.11`
- [`uv`](https://docs.astral.sh/uv/) (recommended) or standard `pip`

### Setup with `uv`

```bash
# Install dependencies and sync virtual environment
uv sync

# Launch Jupyter notebook / lab
uv run jupyter lab
# or run the kernel inside your IDE using .venv/bin/python
```

### Setup with standard `pip`

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
